# Personal portfolio

An editorial, NDA-safe portfolio for a software engineer and mobile product builder.

## Stack

- Next.js (App Router)
- TypeScript
- Plain CSS
- No CMS, component library, analytics, or runtime data dependencies

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Before publishing

Replace `hello@yourdomain.com` in `app/page.tsx` with your real contact address and update the metadata in `app/layout.tsx` with your name.
